## 1. 总原则（来自 Tokens 页）

1. 字号只用 22 / 17 / 13 / 11 四档，字重只用 Regular 与 Semibold。
2. 颜色只用「美卡 · 颜色」11 个 token，浅色、深色各一套值。不用渐变。
3. 4/8 网格，唯一例外是 2（名字与 @handle 之间）。页面左右边距 20，列表行上下内边距 12，0.5pt 发丝分隔线。
4. 所有可点元素最小 44×44；视觉小于 44 的加透明热区，不改变布局。
5. 只用 Lucide 图标，24 / 20 / 16（稿内另有 22、19、18、17、16、15、14、13 等系统栏与行内尺寸，见 §3）。界面框架内不用 emoji。
6. 加载：请求超过 200ms 才出骨架；超过 3 秒在原位显示「正在等待论坛响应」；错误原地显示，不弹全屏错误页；HTTP 状态码等技术细节只在「高级 › 诊断」里出现。
7. 全部文字跟随系统动态字体；所有图标按钮有 VoiceOver 标签；通知行朗读先读「未读」或「已读」。

### 2.6 点击区域、手势、加载、图标、无障碍、工程落地

原文较长，以 Figma Tokens 页为准，要点：

- 置顶折叠行视觉高 36，上下各扩 4 透明热区，合计 44；单行「置顶 · 标题」。
- 工具栏按钮、楼层按钮、AI 总结里的楼层链接都 ≥ 44×44；放不下合并为「等 N 楼」。
- 正文内联 @提及与链接：点击区域按行高扩展到 ≥ 44 或整段可点。
- 手势：不做页面级左右横滑切分类；列表行左滑露出「书签」「标为已读」两个按钮（不支持全程滑动直接触发）；去掉「第一个分类右滑打开抽屉」；阅读页下滚时工具栏收成 44，上滑或停止后展开；长按任意楼层 = 楼层浮起 + 上下文菜单（含「添加笔记」）。
- 工具栏：占位 64 + 安全区 34，位于正文下方不覆盖内容；收起态 44，楼层号放 32 高胶囊（浅 #F2F2F7 / 深 #1C1C1E）并保留 Lucide `arrow-up-down`，整条 44 可点。按钮只作用于整帖或一个明确楼层：回复 = 回复主题；铃铛 = 本帖通知级别；书签、分享 = 整帖；楼层按钮 128×48 显示「#楼号 / 最高楼层」，打开楼层跳转半屏。工具栏不放点赞。
- 楼层跳转半屏：「跳转」读取输入楼层号，校验 1–N 后一次点击直接跳；无效时留在输入框并显示有效范围。时间轴是可访问滑块（VoiceOver 上下轻扫调楼层）。
- 图标落地两步：先收拢到 AppIcons（视觉不变），再在 AppIcons 内切 Lucide。

## 7. 设计决策

### 7.1 Figma 稿内部前后不一致（实现时按 7.2 的决定处理）

1. 按钮填充色：Tokens 表 brand/button 浅色 = #2E6F55，但阅读页浅色帧「回复」「跳转」填的是 #173E31；深色帧用 #2E6F55。

3. 首页导航：浅色帧标题居中；深色帧标题放在左侧 90 宽槽里，右侧留了一个 90 宽空槽。
4. 字母头像与 @handle：阅读页楼层 34 + 11；短帖帧作者 40 + 13。
5. 正文列表圆点深色为 #EBEBF0，不在 11 色内。
6. 工具栏底色：长帖帧浅深都是半透明；短帖、正文渲染的深色帧是实色 #000000。
7. 交接说明提到的「横屏帧」在 Figma 阅读页里没有找到。

## 8. 与现状的差异（实现时要改的行为）

- 底栏：默认三项（首页、通知、我的）+ 常驻搜索胶囊；不再随滚动隐藏。
- 首页：去掉 ☰ 分类抽屉、搜索胶囊行、分类 chips 行、FAB；去掉「第一个分类右滑打开抽屉」；分类切换只靠分类条点选。
- 通知：新增筛选；快捷面板取消。
- 列表行：左滑露出「书签」「标为已读」。
- 帖子：长按楼层出上下文菜单；「⋯ 更多」弹层与头像径向菜单取消；笔记按楼层存。
- 所有对话框、底部弹层统一换成 §4 的对话框 / 半屏 / 操作表外壳；不再出现 Material 下拉菜单。
- 颜色：彩色分类方块、彩色图标方块、通知类型色、回复数热度色、金银铜色、彩色日志条、橙 / 红提示条全部去掉（只剩 11 色 + §6 的强调色备选）。
- 错误：整页 ErrorView 改原地错误；「查看详情」和 HTTP 细节移到「高级 › 诊断」。
- 设置：新增「高级 › 诊断」；外观新增字体导入、预设、微调、强调色、实时预览；正文字号并入外观。
